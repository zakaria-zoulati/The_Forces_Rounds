# The Forces Rounds

**TheForces Rounds** is a community-driven series of Codeforces-style competitive programming contests created by CP enthusiasts for the CF community, aimed at participants ranging from beginners to masters. Check out the official site at [theforces.netlify.app](https://theforces.netlify.app). This repository contains my personal solutions to problems from various TheForces rounds, all written in C++.
